Start the Local Daemon

The browser extension needs the local Python daemon running on port 18999 to communicate with your agent.

1. Install or update the Python package
py -m pip install -U agent-browser-bridge
2. Start the bridge daemon
py -m agent_browser_bridge daemon start
3. Configure your AI agent client (optional)
py -m agent_browser_bridge setup
Troubleshooting & Health Check
py -m agent_browser_bridge doctor
PATH-proof commands: Leading with py -m works even if agent-bridge is not recognized in your terminal. Once the daemon starts, this page will update automatically.
