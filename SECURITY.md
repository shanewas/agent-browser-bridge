# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately
through GitHub's private vulnerability reporting:

https://github.com/shanewas/agent-browser-bridge/security/advisories/new

Include what you found, the version you tested, and the steps to reproduce it.
You should get an acknowledgement within a few days. Once a fix is out, the
advisory is published with credit to the reporter unless they prefer otherwise.

## Supported versions

Only the latest release is supported. Fixes land there first and are not
backported to older versions, so please confirm a problem still exists on the
current release before reporting it.
